# ab-platform-calutron
Calutron — платформа A/B-экспериментов. Calutron помогает продуктовым командам пройти путь от гипотезы и подготовки аудитории до сравнения вариантов и фиксации решения. Платформа объединяет online- и offline-эксперименты, сплитование со стратификацией, донабор по расписанию, A/B-тоглы и работу через AI-ассистентов.
